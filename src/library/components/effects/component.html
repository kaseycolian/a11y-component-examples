5 · Two gates, different reach

fx-pulse

calc(var(--ac-motion) * 1.8s)

The attribute is on both boxes, and both resolve --motion to 0. The left box keeps going anyway, because the rule that stops fx-pulse is looking for an ancestor. Reduce motion in the header sets the same attribute on <html> and stops both — and an operating system asking for reduced motion stops both too, because that rule targets the element directly.

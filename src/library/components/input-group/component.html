Correct examples

All five are markup you can copy. Four of them join something to the field — a submit button, a password reveal, a copy button, a text affix — and the fifth shows what changes when the value is wrong.

1 · Submit button

Enter submits too. The button is a second route to it, not the only one.

2 · Password reveal

Revealing does not move the caret or clear the field.

3 · Copy to clipboard

Read-only, so it can still be focused and selected by hand.

4 · A link is not a color

The setlist ran short, so they played the heading list twice and nobody in the room objected.

  1. ac-t-link — underlined, so the cue is not the color
  2. color only — 1.27:1 against the text beside it, where 3:1 is the floor

Both are real links, and both are 13:1 against the background, which is the number people check. Take the color away — print it in gray, or read it through a screen tint — and only the first one is still a link.

Correct example

This is the markup to copy. One container, element selectors for everything inside it, and the three attributes a scrolling box owes: a tab stop, a role and a name.

1 · One container, styled by element

Exporting a report

A report covers the last 30 days by default. This one holds 462 rows, and a wider export is capped at 99 columns. There is a longer guide to the export format in the help centre, and it goes further than this page does.

What is included

Every order in the range, with its customer, total and status. Draft invoices are left out unless you ask for them.

  • Order number and date
  • Customer name and email
  • Total, tax and status

The export is a flat file and the request is one line:

curl -s https://api.example.com/reports?project=462&range=30d | jq '.rows[] | .total'

Everything past the fold is real text, in the accessibility tree, and reachable by keyboard. That is the whole component.

The surface scrolls, so it takes a tab stop, a role and a name. Data Table owns those three attributes; this page is about what goes inside.

Common mistakes

These four are live and wrong on purpose. Every readout under them is written by hand and asserted against the real accessibility tree by the spec, so none of it can drift.

A scroller inside a scroller is still a scroller, and needs the same three attributes the surface has. Not white-space: pre-wrap: code that wraps wherever it likes reads as different code.

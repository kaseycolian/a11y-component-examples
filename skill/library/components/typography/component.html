Common mistakes

Four failures, live rather than described. Each one looks correct on screen and correct in the markup, and two of them are invisible to axe.

One entry, two lines. The <div> is unreachable by heading navigation and announces as a paragraph. Fixing it is one tag, not one class.

3 · Muted text set with opacity

Invoice 99 was paid on the 3rd, and the receipt went out the same afternoon.

  1. ac-t-body — 17:1
  2. ac-t-muted — 9.5:1, and it is a color
  3. opacity: 0.4 — 3.7:1 at best, 2.5:1 in the light themes, and no number appears in the CSS

All three are the same sentence. The third fails SC 1.4.3 from a declaration that names no color at all. Change the theme in the header and watch the ratio move.

4 · Link shown by color only

The totals looked right, so nobody opened the reflow example before Invoice 99 went out.

The totals looked right, so nobody opened the heading list before Invoice 99 went out.

  1. ac-t-link — underlined, so the cue is not the color
  2. color only — 1.27:1 against the text beside it, where 3:1 is the floor

Both are real links, and both are 13:1 against the background, which is the number people check. Take the color away and only the first one is still a link.

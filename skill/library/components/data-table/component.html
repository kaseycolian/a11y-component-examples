This is the markup to copy. Four elements and two attributes — a caption, a thead, scope both ways, and a wrapper that can be named. No script.

Common mistakes

These four are live and wrong on purpose. Every readout under them is written by hand and asserted against the real accessibility tree by the spec, so none of it can drift.

The column name is now in the cell and in the header, so it is read twice. The label was added because the header row was clipped — and clipping keeps it in the accessibility tree.

The roles survive: Chromium 151 still reports table, row and cell under display: block. What is gone is the column on screen.
